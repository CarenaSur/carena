# Carena

Pantalla de la app de campo de Carena (entrenamiento personal a domicilio). Uso privado.

Este repositorio contiene solo la interfaz. No contiene datos ni claves, y la app no muestra nada sin un dispositivo vinculado por su titular.

- `index.html`: la app (generada; no se edita a mano).
- `sw.js`: guarda la pantalla en el dispositivo para abrir sin conexión. No guarda datos.
- `manifest.webmanifest`, `icons/`: nombre e icono al instalarla.
